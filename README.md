# Estudos de Linguagem C

Repositório com exercícios desenvolvidos durante meus estudos de lógica de programação e linguagem C na graduação em Engenharia de Software.

## Exercícios

- **ola.c:** um dos meus primeiros programas em C.
- **orçamento.c:** exercício para praticar entrada de dados e estruturas condicionais, usando uma resposta para confirmar ou não um orçamento.

## Como executar

É necessário ter o compilador GCC instalado.

Para compilar e executar o exercício de orçamento no Linux:

```bash
gcc -Wall -Wextra "orçamento.c" -o orcamento
./orcamento
```
